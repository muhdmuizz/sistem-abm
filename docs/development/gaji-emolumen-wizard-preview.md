# Gaji & Emolumen wizard preview

Baseline: `6ee13ec72c5e7c54c060466b4407c9c06a1b3d41`. Requirements: draft PR #117. Local preview for interface review using synthetic example data. The auth-protected page is available when the application environment is local and the user can use Bida Peruntukan.

JIK generates Isi/Kosong rows and calculates Kekosongan. The OS11000 preview uses the four confirmed TPG allocations. Kosong rows use a sample median and a fixed three months. The proposed Ketua Jabatan selector uses named Isi rows for the example workplace. Re-generating the grid replaces the sample wizard entries.

No persistence, migrations, actual payroll reference data, OS12000/OS13000 calculation, or workflow permissions for live payroll are included. JavaScript syntax was checked. Browser and GitHub Actions verification remain pending.
