# Shared rule — mandatory applicable Kadar across Anggaran (OS)

**Owner-confirmed:** 12 November 2026. **Scope:** Universal reference and completeness principle only; no new financial formula or implementation.

Every **applicable Kadar** in every Anggaran (OS) is **mandatory**, regardless of its source:

| Kadar mode | Requirement |
| --- | --- |
| Approved automatic lookup / calculation | System must obtain the applicable Kadar from its verified reference and formula. |
| Approved user entry | User must enter the applicable Kadar. |
| Missing or unresolved | An item requiring that Kadar cannot be considered complete until the applicable Kadar is established. |

This is a **completeness requirement**, not permission to replace a missing prescribed rate with arbitrary user input, invent a rate, impose a universal rounding rule, or change an OS-specific Kadar mode. Apply only where a Kadar is applicable. Jawatan and Gred are never category levels.

**No application, PostgreSQL, Architecture Decision or master-catalogue data is changed by this documentation.**
