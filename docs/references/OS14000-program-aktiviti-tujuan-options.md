# OS14000 — Program/ Aktiviti/ Tujuan reference clarification

**Status:** Confirmed by user on 12 November 2026.  
**Scope:** Reference wording only; no new calculation, validation, or implementation rule.

For **OS14000 — Bayaran Lebih Masa**, the field **Program/ Aktiviti/ Tujuan** uses the following references:

| No. | Selection |
| --- | --- |
| 1 | **Actual Program/ Aktiviti** registered in the system |
| 2 | Kerja-kerja jangka masa terhad |
| 3 | Kerja-kerja mustahak yang tidak boleh ditangguh |

The original reference option **“Aktiviti/ Program/ Mesyuarat rasmi”** is **replaced with the actual Program/ Aktiviti**. It must not remain as an independent fixed option.

The other two fixed-purpose options are retained. The user stated the remaining OS14000 reference requirements are already available and did not request changes to them.

**Implementation status:** Documentation only. No Laravel application changes or database modifications are implied. No other OS rules or Architecture Decisions are modified by this clarification.
